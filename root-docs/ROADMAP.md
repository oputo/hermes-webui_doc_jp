## アーキテクチャ

| レイヤー | ファイル | 状態 |
|---|---|---|
| Python サーバー | `server.py` ＋ `api/` モジュール | `api/` のビジネスロジック（config, sessions, streaming, profiles, routes, onboarding, workspace, updates, upload）上の薄い HTTP シェル ＋ 認証ミドルウェア |
| HTML テンプレート | `static/index.html` | ディスクから配信 |
| CSS | `static/style.css` | テーマ ＋ スキン、モバイルレスポンシブ、KaTeX、テーブルスタイル |
| JavaScript | `static/{ui,sessions,messages,workspace,panels,boot,commands,icons,i18n,login,onboarding}.js` | 静的ファイルとして配信される vanilla-JS モジュール — バンドラなし |
| サービスワーカー | `static/sw.js` | オフラインシェルキャッシュ、バージョン固定アセット |
| Docker | `Dockerfile`, `docker-compose.yml` | `python:3.12-slim`、マルチアーキ（amd64+arm64）、HEALTHCHECK |
| CI/CD | `.github/workflows/` | 全 PR で ruff lint ＋ シャード pytest ＋ ブラウザスモーク ＋ Docker スモーク。タグ push で自動リリース ＋ GHCR 公開 |
| テスト隔離 | `tests/_pytest_port.py` | worktree ごとのポート ＋ 状態ディレクトリ導出、衝突なし |

> ファイルごとの行数はリリースごとにずれます。現在のモジュールマップは `ARCHITECTURE.md`、正確なサイズは `git ls-files` を参照。

- リアルタイムマルチユーザーコラボレーション — 全体が単一ユーザー前提
- プラグインマーケットプレイス — Hermes skills がこの面をカバー
- Anthropic / Claude 独自機能 — Projects の AI メモリ、Claude artifacts 同期（再現不可能）
