## 既知の制限

- **2コンテナ Docker 構成: ツールが WebUI コンテナで動く** — 2コンテナ構成（hermes-agent と hermes-webui を別コンテナ）では、WebUI 起動のエージェントセッションは、エージェントコンテナではなく WebUI コンテナでツールを実行します。これは既知のアーキテクチャ上の制約です。回避策: 統合シングルイメージ方式を使うか、エージェントコンテナ内の CLI でセッションを開始する。(#681)

- **チャット内画像とワークスペース保存画像の不一致** — エージェントが（URL から）インライン画像を表示し、ユーザーがその画像の保存を依頼すると、エージェントは新たにダウンロードを発行し、ソース URL が CDN ローテーションまたはパラメータ化されている場合は異なるファイルを返すことがあります。WebUI はエージェントが提供する URL を正しく描画します。修正にはエージェント側の URL キャッシュが必要です。(#641)

- **MCP ツールが WebUI セッションで利用できない** — MCP サーバーはアクティブプロファイルの config.yaml の mcp_servers: 配下に設定する必要があります。MCP ツールが現れない場合、プロファイルが正しいか、MCP サーバープロセスが WebUI コンテナ内部から到達可能かを確認してください。(#628)

- **並行セッションでの os.environ レースコンディション** — 並行エージェントセッションは TERMINAL_CWD、HERMES_SESSION_KEY、HERMES_HOME についてプロセスレベルの os.environ を共有します。_ENV_LOCK は変更を直列化しますが、エージェント実行中の環境変数を完全には隔離しません。hermes-agent 側の上流修正が保留中です。(#195)

## 修正済み

### ~~セッションタイトルの切り詰め / ホバーアクション~~ -- 修正済み（Sprint 16）

- **以前:** アクションアイコンが不可視でも約 30px のスペースを確保し、タイトルを切り詰めていた。
- **修正:** 全アクションボタンを `position:absolute` の `.session-actions` オーバーレイコンテナでラップ。タイトルが利用可能な全幅を使うように。アクションはホバー時に右端からのグラデーションフェードで現れる。

### ~~フォルダ/プロジェクト割り当ての操作が粘着く~~ -- 修正済み（Sprint 16）

- **以前:** セッションがプロジェクトに属するとき、フォルダアイコンが恒久的に表示されたまま（青、不透明度 60%）だった。
- **修正:** `.has-project` の恒久ボタンを、プロジェクト色に一致する色付き左ボーダーに置換。フォルダボタンは他の全アクション同様、ホバーオーバーレイ内にのみ現れるように。

### ~~プロジェクトピッカーのクリッピングと幅~~ -- 修正済み（v0.17.3）

- **以前:** ピッカーが `.session-item` 祖先の `overflow:hidden` でクリップされていた。`position:fixed` では包含ブロックが幅を制約せず、ピッカーがビューポート全幅に伸びていた。
- **修正:** 動的な幅計算（最小 160px、最大 220px）。イベントリスナーの順序変更。クリーンアップシーケンスを修正。(PR #25)

### ~~モデル検出での NameError クラッシュ~~ -- 修正済み（v0.17.3）

- **以前:** カスタムエンドポイントの `except` ブロックで `logger.debug()` が呼ばれていたが、`config.py` で `logger` がインポートされていなかった。失敗したエンドポイント取得ごとに `NameError` でクラッシュ。
- **修正:** 静かな `pass` に置換 — ローカル LLM が未設定なら到達不能エンドポイントは想定内。(PR #24)
