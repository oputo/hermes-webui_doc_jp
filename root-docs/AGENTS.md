# Hermes WebUI のエージェント向け指示

このファイルは、本リポジトリで作業する AI アシスタント向けの共有エントリポイントです。プロジェクト固有で、公開しても安全な内容に保ってください。個人のマシンセットアップ、プライベートなネットワーク詳細、認証情報、トークン、ローカル限定のワークフローメモをここに置かないでください。

## まず読む

変更を加える前に、次を読んでください:

1. `README.md`
2. `CONTRIBUTING.md`
3. `docs/CONTRACTS.md`
4. `CHANGELOG.md`

アーキテクチャ、テスト、セットアップ作業では、対応するリファレンスも読んでください:

- 設計制約と現在のモジュール構成は `ARCHITECTURE.md`
- ローカル検証コマンドと手動テストガイダンスは `TESTING.md`
- 初回オンボーディング挙動は `docs/onboarding.md`
- 診断フローは `docs/troubleshooting.md`
- より大きな RFC と state/durability コントラクトは `docs/rfcs/README.md`

UI や UX 作業では、レイアウト、対話フロー、テーマ、チャット描画、コンポーザクロムを変更する前に `docs/UIUX-GUIDE.md` と `DESIGN.md` を読んでください。

## オンボーディングと再インストールのサポート

タスクがインストール、再インストール、bootstrap、初回オンボーディング、プロバイダー設定、ローカルモデルサーバー設定、Docker オンボーディング、WSL オンボーディング、または失敗した初回起動のサポートを含む場合、コマンド実行やログ調査の前に `docs/onboarding-agent-checklist.md` を読んでください。

そのチェックリストの安全ルールに従ってください:

- 人間が実状態の使用を明示的に求めない限り、試行には隔離した `HERMES_HOME` と `HERMES_WEBUI_STATE_DIR` を使う
- 明示的な承認なしに実運用の `~/.hermes` ディレクトリを削除・上書きしない
- API キー、OAuth トークン、Cookie、`.env` の全内容、`auth.json` の全内容、パスワードハッシュを出力しない
- 修正を推奨する前に、非シークレットのステータスとログのエビデンスを収集する

## コントリビューションスタイル

- 1つの PR には1つの論理変更。無関係なリファクタやクリーンアップは分割する。
- 触れるサブシステムについて、編集前に `docs/CONTRACTS.md` とリンクされた contract/RFC を読む。
- 既存の Python ＋ vanilla JavaScript 構造を優先する。明確な正当化とロールバックの筋書きなしに、依存、ビルドツール、フレームワーク、長寿命プロセスを追加しない。
- セットアップ、オンボーディング、ランタイム挙動、アーキテクチャ、テストガイダンス、ユーザー向けワークフローを変更したらドキュメントを更新する。
- リリースノートになり得る、ユーザー可視の挙動・セットアップ・ワークフロー・ドキュメント変更については `CHANGELOG.md` を更新する。
- UI や UX 変更では、before/after のエビデンスを含め、関連するデスクトップ・狭幅・モバイル状態をテストする。
- 挙動変更では、実用的な範囲で自動テストを追加・更新し、実施した手動検証を列挙する。
- ランタイム、ストリーミング、復旧、リプレイ、圧縮、サイドバーメタデータの変更では、変更する state レイヤーを名指しし、該当する不変条件を証明する。

## ローカル状態とシークレット

Hermes WebUI は実エージェントの状態、セッション、ワークスペース、認証情報、cron データを読み書きできます。アクティブな状態ディレクトリを確認していない限り、ローカル検証は破壊的になり得ると扱ってください。

実験には隔離した試行状態を優先してください:

```bash
HERMES_HOME=/tmp/hermes-webui-agent-home \
HERMES_WEBUI_STATE_DIR=/tmp/hermes-webui-agent-state \
HERMES_WEBUI_PORT=8789 \
python3 bootstrap.py
```

このトラッキング対象ファイルにプライベートなマシン指示を含めないでください。個人のワークフロー詳細には git-ignore されたローカルノートを使ってください。
